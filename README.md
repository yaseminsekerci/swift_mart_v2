# SwiftMart

Flutter ve Dart ile geliştirilmiş mobil e-ticaret uygulaması prototipi.

## Kullanılan Teknolojiler
- **Framework:** Flutter
- **Dil:** Dart

## Proje Yapısı
- `lib/`: Uygulama ekranları ve temel kod dosyaları
- `android/` & `ios/`: Platform yapılandırmaları
- `assets/`: Görsel ve kaynak dosyaları
